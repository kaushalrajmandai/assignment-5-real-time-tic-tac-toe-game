# Real-Time Tic Tac Toe

Socket Programming Assignment | Node.js + Express + Socket.io + MongoDB

## Description
A real-time multiplayer Tic Tac Toe game where two players can join with a username, get assigned X/O, play in real-time with instant move sync, and have their game results saved to MongoDB.

## Technologies Used
- Node.js
- Express.js
- Socket.io
- MongoDB (Mongoose)
- HTML, CSS, JavaScript

## Features
- Username-based login (first player gets X, second gets O)
- Real-time move synchronization across clients
- Turn management and win/draw detection
- Game history saved to MongoDB
- Game reset functionality
- Max 2 players per game
